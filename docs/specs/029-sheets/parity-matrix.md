# Parity matrix

**Status: specified.** Nothing is built.

Every surface of Google Sheets, one row each, with what LiveDoc does about it. The rows are the
[inventory](../../research/sheets-open-standard/google-sheets-inventory.md)'s, in its order; the functions have
their own catalogue ([Formulas](formulas.md#function-catalogue)).

## Reading a row

- **Rule**: the item does in a spreadsheet what it does in Google Sheets, as the reference capture shows
  ([Reference captures](../../research/sheets-open-standard/reference-captures.md)), under the area spec named in
  **Spec**, which states its share roles, keyboard, accessibility, telemetry, errors and limits. Where the area
  spec differs from Google, the area spec wins and says why.
- **Status**:
  - **planned**: to be built; becomes **built** with the name of the test that proves it.
  - **left out (C3)**: Webber ruled it out (scripting, macros, add-ons, any assistant, smart chips, Google's own
    services); a file carrying it keeps it, never runs it ([Spreadsheet](spreadsheet.md#left-out)).
  - **either way (ask)**: could be built on LiveDoc's own services or left out; on the list below, asked of Webber
    once with this matrix.
- Google's names, logos and artwork never appear in the product: a row that names Google (Drive, Gemini) is matched
  by LiveDoc's own equivalent or left out.
- Telemetry is never per row: each area's events are named in its spec.

## Rows that could read either way

Asked of Webber once, with this matrix (C3):

| Row                                           | Built as                                                                     | Or       |
| --------------------------------------------- | ---------------------------------------------------------------------------- | -------- |
| File › Email; Email collaborators             | LiveDoc's mail where email is configured (as notification rules)             | Left out |
| File › Move; Add shortcut to Drive            | The Explorer's Move to folder; a shortcut has no LiveDoc equivalent          | Left out |
| Tools › Create a new form                     | A LiveDoc form whose responses land in a new sheet (C4 keeps form responses) | Left out |
| Tools › Activity dashboard                    | Who viewed and edited, from the Timeline                                     | Left out |
| Tools › Conditional notifications             | Notification rules on a range's values                                       | Left out |
| Chart › Publish chart                         | LiveDoc's share link to a chart                                              | Left out |
| Help › Training, Updates, Help Sheets improve | The help centre, What's new, feedback                                        | Left out |
| `DETECTLANGUAGE`                              | Script and language detection in the browser                                 | Left out |
