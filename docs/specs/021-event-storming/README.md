# Event storming

Follow the references below only as needed; never upfront.

- ./event-storming.md - when working on Event storming: the workshop tab kind, its note notation, stationery, Alt insertion, timeline lanes (every workshop note always on a lane), next-note buttons and the photo import (sticky-vision detector, sticky-model boundary model, handwriting readers)
- ./board-reading.md - when reading what a board says without a model: relations, the timeline, chains, gaps
- ./suggestions.md - when an agent proposes notes, or a person sees, applies or dismisses them (hints, Show All)
- ./asks.md - when a person asks for suggestions: the topics, the three hands (CLI, MCP, built-in model), the prompt, the About, what was declined
- ./suggested-changes.md - when an agent proposes a change to what is on the board: context names, merge names, rewording that ripples, re-kind, split, remove
- ./board-language.md - when working on the board's terms: how a term is matched, the Language tab, Rename Term
- ./lane-plans.md - when reorganising a board into 2 to 12 lanes: the plan, placing, the check, the fold
- ./board-structure.md - when working on pivotal events, phases, lane names or hotspot answers
- ./board-review.md - when working on the Review panel: readiness, Check (the gaps for a person), Story
- ./candidate-contexts.md - when notes are grouped into candidate contexts (agent-suggested dashed outlines)
- ./domain-export.md - when turning a board into a spec and domain types: the bundle, the brief, CLI, MCP and zip
