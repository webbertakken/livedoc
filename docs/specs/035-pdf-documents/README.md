# PDF documents

Follow the references below only as needed; never upfront.

A **PDF document** is one PDF, read, reviewed and really edited by people together, live, and always a PDF: the file
that leaves is a PDF any reader opens, and one nobody changed leaves byte for byte as it came. Its functions are
measured against Acrobat's. The research is in `docs/research/pdf-documents/`.

- ./editing-modes.md - when working on Viewing, Reviewing and Editing: what each may do, switching, what the others see
- ./parity-matrix.md - when checking what of Acrobat is built, specified or left out: one row per help topic
- ./opening.md - when working on reading a PDF: what is read, damaged files, passwords, the named refusals, limits
