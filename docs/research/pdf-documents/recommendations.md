# Recommendations

One row per decision of this research, each with the designs compared and what is recommended. Researched November 2026. A recommendation that settles a fork is Webber's to rule; until then it stands as a default.

| Decision                 | Designs compared                                                                        | Recommended                                                                                                                 | Evidence                                                     |
| ------------------------ | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| The engine               | PDFium for everything; PDF.js with LibPDF; an own parser and writer; PDFium with LibPDF | **PDFium reads, draws and edits pages; LibPDF writes what Reviewing adds and signs**, behind one interface of LiveDoc's own | [The engine](engine.md): spikes on 112 files                 |
| The live model           | Base and layer; rewrite the bytes; a converted model                                    | **An immutable base and a live layer in the room**, baked when a file is asked for                                          | [The live model](live-model.md)                              |
| The layer's state        | A sequence CRDT; element operations                                                     | **The sequence CRDT**, in the text document's storage generalised (a shared piece, routed to its owner)                     | [The live model](live-model.md)                              |
| Saving                   | Incremental update; rewrite                                                             | **Incremental for what sits on a page, rewrite for what changes a page**; an empty layer is never baked                     | [Saving](saving.md)                                          |
| Uploading                | One streamed request; parts through the Worker; signed addresses; base64                | **One request to 32 MiB, parts above it**, keyed by SHA-256                                                                 | [Bytes](bytes.md)                                            |
| Reading the bytes        | Whole; by range                                                                         | **Whole under 8 MiB, by range above**, through the engine's block reader                                                    | [Bytes](bytes.md): blocks asked for, per file                |
| This Browser             | The origin private file system; IndexedDB Blobs; inside the record                      | **The origin private file system**, the record holding the key only                                                         | [Bytes](bytes.md)                                            |
| Without object storage   | A named failure; chunks in the room                                                     | **A named failure**, as images                                                                                              | [Bytes](bytes.md)                                            |
| How large a file (F6)    | 25 MiB; 100 MB; 1 GB; usage only                                                        | **100 MB**                                                                                                                  | [Bytes](bytes.md): the platform's limits and timings         |
| Drawing pages            | A canvas a page; tiles; vector output                                                   | **Tiles from the engine's worker**, a whole-page bitmap first                                                               | [Rendering](rendering.md)                                    |
| Text over the page       | DOM text; selection drawn by LiveDoc; both                                              | **Both**: LiveDoc's selection for the pointer and marks, real DOM as the accessible tree                                    | [Rendering](rendering.md), [Accessibility](accessibility.md) |
| Dark pages (C3)          | A CSS filter; forced colours; lightness mirrored; mirrored with photographs put back    | **Mirrored in OKLab on a contrast-keeping curve, photographs put back**, as a step after the engine                         | [Dark pages](dark-pages.md): six pages, four designs         |

| Field scripts (F11)      | Run them sandboxed; recognise the standard actions; ignore                              | **Recognise the standard actions**; no script from a file runs                                                              | [Fields](fields.md)                                          |

| Checking signatures (C4) | The engine; an own check on Web Crypto                                                  | **An own check on Web Crypto**, saying what it cannot know (whether the issuer is trusted)                                  | [Signing](signing.md): agrees with poppler                   |
| Comments                 | Threads written out as annotations; annotations as the model; beside the file           | **LiveDoc's threads, anchored to marks, written as annotations with replies and state**                                     | [Comments](comments.md)                                      |

| What the servers need    | The Worker; the browser; both                                                           | **The Worker where the file fits, the browser otherwise**, a browser's upload for display only                              | [What the servers need](servers.md)                          |

## Forks, as the research leaves them

| Fork                              | Default                                               | What the research adds                                                                                  |
| --------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **F5** The reference              | Acrobat's function inventory                          | **Ruled (Webber, 2026-11-21)**: Acrobat's 403 help topics, as read in the inventory                     |
| **F6** How large a file           | 25 MiB until measured                                 | **Ruled (Webber, 2026-11-21)**: 100 MB, for every file tab                                              |
| **F7** Share roles for Reviewing  | A Participant reviews; a Viewer reads                 | **Ruled (Webber, 2026-11-21)**: a Participant does all of Reviewing, certificate signatures included    |
| **F8** Editing a signed PDF       | Warn, ask once, keep the signed version               | Measured: Reviewing never breaks a signature, Editing always does; asked in Phase 11                    |
| **F9** Passwords and permissions  | In memory only; locked files open in Viewing          | Permissions are a request, not a lock: a locked file is fully readable by any reader; asked in Phase 11 |
| **F10** Scanned pages             | Recognition in the browser, on demand                 | Measured: 4.0 MB once, about 4 s a page, 9 words in 10 at 150 dpi; asked in Phase 16                    |
| **F11** Scripts and dynamic forms | No script runs; safe functions; XFA's static fallback | A count on real forms is owed before it is asked in Phase 10                                            |
| **F12** Starting from nothing     | None                                                  | Nothing new; asked in Phase 19                                                                          |
| **F13** The first-time question   | Once per person                                       | The recolouring is chosen from four designs; its four drawn options come in Phase 7                     |
| **F14** The inventory's edge      | Left out, data kept untouched                         | **Ruled (Webber, 2026-11-21)**: left out, their data in a file kept untouched                           |

## What the research could not settle

- Budgets on a deployed Worker and on phones (Phase 4's tracer bullet, Phase 20).
- New text in complex scripts (shaping), and whether a tagged file's structure survives an edit (Phase 12).
- How much of real forms the standard actions cover (before Phase 10), and real signed files from Webber's own work.
- Files only Acrobat and Preview can judge: neither runs here, so those rows are Webber's captures in Phase 21.
