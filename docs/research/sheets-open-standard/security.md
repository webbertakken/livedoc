# Security of spreadsheet files and functions

Follow the references below only as needed; never upfront.

Abuse cases for imports, exports and functions that fetch. Researched 2026-11-18. Each case becomes a test with a
named rejection in Phase 7 or 13; those of a file opened are built
([Import security](../../specs/029-sheets/files-and-print.md#import-security)).

| Case                                    | How it bites                                                                                                                                 | Guard                                                                                                                                                                                     |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Formula injection in CSV                | A downloaded field starting `=`, `+`, `-`, `@`, tab or carriage return runs as a formula in Excel or Sheets (OWASP's CSV injection, assumed) | Already guarded for downloads (`sheet.md` "Safe to open", verified); kept for TSV, extended to XLSX and ODS text cells that look like formulas (stored as text, never as formulas)        |
| Zip bombs                               | A tiny `.ods` or `.xlsx` inflating to gigabytes                                                                                              | The shared byte budget of `zip-reader.ts` (verified); a cap on entries and on the ratio per entry                                                                                         |
| XML external entities                   | A `<!DOCTYPE>` with entities reading files or URLs, or billion laughs                                                                        | A parser that never resolves external entities and refuses any DTD (`saxes` reports a doctype; refuse it, inferred)                                                                       |
| Macros and scripts                      | ODS `Basic/` and `Scripts/` folders, XLSM `vbaProject.bin`                                                                                   | Never run; dropped on import with a notice, never written back (a listed loss)                                                                                                            |
| External links                          | `IMPORTRANGE`, `HYPERLINK` with `javascript:`, external workbook references                                                                  | Link schemes allow-listed (`safeHyperlink`, verified); external workbook references kept as text with their cached values                                                                 |
| Fetches to private addresses            | `IMPORTXML("http://169.254.169.254/...")` from a Worker                                                                                      | A Worker that resolves the host, refuses private, loopback, link-local and metadata ranges, follows no redirect to them, caps size and time ([fetching functions](fetching-functions.md)) |
| Fetches as a tracker                    | `IMAGE` or `IMPORTDATA` reveal a viewer's address to a third party                                                                           | Fetched by the Worker, never by the viewer's browser                                                                                                                                      |
| Huge numbers of styles, names or sheets | Memory exhaustion on import                                                                                                                  | Caps per kind with named rejections, as the store's limits today                                                                                                                          |
| Regular expressions                     | Catastrophic backtracking                                                                                                                    | Already bounded (`regex-cost.ts`, verified)                                                                                                                                               |
