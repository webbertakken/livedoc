# The Google Sheets inventory

Follow the references below only as needed; never upfront.

Every surface of Google Sheets on a desktop browser, as the reference for the parity matrix
(`docs/specs/029-sheets/`, Phase 3). Gathered 2026-11-18.

How each part is known:

- **Shortcuts and limits**: Google's own help pages, parsed (verified, with links).
- **Menus, toolbar, context menus, panels, dialogs and chips**: written from the product as it stands in late 2025
  (assumed). Each is to be confirmed against a reference capture before its matrix row is marked built
  ([Reference captures](reference-captures.md)); Google moves items between menus often.

## Toolbar, left to right

Search the menus (the tool finder) · Undo · Redo · Print · Paint format · Zoom · Format as currency · Format as
percent · Decrease decimal places · Increase decimal places · More formats (123: the Number menu) · Font · Font size
(minus, the size, plus) · Bold · Italic · Strikethrough · Text colour · Fill colour · Borders (sides, colour, style) ·
Merge cells (with its menu) · Horizontal align · Vertical align · Text wrapping · Text rotation · Insert link ·
Insert comment · Insert chart · Create a filter (with filter views) · Functions (Σ) · then, folded behind More (⋮)
when narrow; and Hide the menus (^) at the far right.

Above it, the **title row**: the document icon, its name (edited in place), Star, Move, See document status (saved,
offline), then Last edit, Comments history, Present (meet), Share, the account. Under it, the **formula bar**: the
name box, fx, the input. At the foot, the **sheet bar**: Add sheet (+), All sheets (a list), the sheet tabs (each with
its menu arrow), and at the right the **status** of the selection (Sum, with Average, Min, Max, Count, Count
numbers), and the Explore button.

## Side panels and dialogs

- **Side panels** (to the right of the grid): Chart editor (Setup, Customise), Pivot table editor, Conditional
  format rules, Data validation rules, Named ranges, Named functions, Protected sheets and ranges, Alternating
  colours, Column stats, Clean-up suggestions, Slicer editor, Timeline settings, Table settings, Explore, Gemini,
  Version history (a whole view, with its panel of versions).
- **Dialogs**: Find and replace; Custom number formats; Custom date and time formats; Custom currencies; Spreadsheet
  settings (General: locale, time zone, display language; Calculation: recalculation, iterative calculation, max
  iterations, threshold); Import file (six ways: create new spreadsheet, insert new sheet, replace spreadsheet,
  replace current sheet, append to current sheet, replace data at selected cell; separator type; convert text to
  numbers, dates and formulas); Print settings (a full-page view: export to, paper size, page orientation, scale,
  margins, formatting, headers and footers, custom page breaks, alignment); Share; Publish to the web; Email;
  Keyboard shortcuts; Advanced range sorting; Insert image; Drawing; Notification rules; Macros (record, manage);
  Make a copy; Move; Details; Split text to columns' separator chip; Paste formatting chip; Smart fill and
  autocomplete suggestions; Formula suggestions and corrections; the function help card; the error tooltip; Edit
  history card; Merge warning; Protected range warning; Data validation warning and rejection.

## Chips and inline objects

People, File, Calendar event, Place, Finance, Rating, Dropdown (single and multiple choice, with chip colours),
Checkbox, link previews (YouTube, Drive files), Images in a cell, Sparklines, Timeline, Tables (column types: text,
number, date, dropdown, checkbox, people, smart chips; group by views).

## Limits

| -------------------------------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| A cell's characters on conversion from Excel | 50,000                | same page (verified)                                                                                                                                           |
| Columns in a sheet                           | 18,278 (A to ZZZ)     | assumed (widely cited; confirm in Phase 3)                                                                                                                     |
| Pivot table rows (Connected Sheets)          | 200,000               | same page (verified)                                                                                                                                           |
