# Reference captures

Pictures of Google Docs that the parity work is measured against. They stay outside the repository: Google's
interface is the reference for layout and behaviour, never artwork the product or its docs carry
(plan 0019, "Ground rules").

## What public pages give

- Google's help centre shows single controls and dialogs in small, light-scheme pictures inside its articles
  (verified: the keyboard shortcuts article and its siblings, retrieved 2026-11-18). They show a control's place, not
  its measurements, states or the dark scheme.
- Google Docs has no dark scheme on a computer (assumed: dark theme exists in the Android and iOS apps only). The
  captures are therefore light; LiveDoc's own captures stay dark, as the ground rules ask, with a light one beside
  each where the comparison needs it.
- No public page shows a signed-in editor at a known size, open menus, the side panels, the share dialog or
  suggesting mode in use.

## The one request to Webber

Captured at 1440 x 900, browser zoom 100%, a signed-in personal account, a document with a heading, a list, a table,
an image, a comment and a suggestion in it. One PNG each, saved to a folder outside the repository:

1. The whole window, Editing mode, print layout on; then pageless.
2. Each menu open: File, Edit, View, Insert, Format, Tools, Extensions, Help; each submenu with a second level open
   (File > Download, Insert > Smart chips, Insert > Break, Format > Text, Format > Paragraph styles, Format > Align and
   indent, Format > Line and paragraph spacing, Format > Bullets and numbering, Format > Table, Tools > Preferences).
3. The toolbar at 1440, 1024 and 768 wide, showing where the overflow starts.
4. Context menus on text, a table cell, an image and a link.
5. The side panels: outline with document tabs, comments, version history, image options.
6. The dialogs: Share, Page setup, Word count, Find and replace, Special characters, Table properties, Custom
   spacing, Columns, Link editor, Preferences (both tabs), Keyboard shortcuts.
7. Suggesting mode with a suggestion selected; a comment thread with a reply, a mention and an assignment.
8. A phone at 390 x 844 (the mobile site, or the app if that is what Webber uses) reading and editing.

Until they arrive, the parity work proceeds on the inventory's assumed rows and marks each as not yet checked against
a capture.
